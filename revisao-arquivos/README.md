# Arquivos — aguardando aprovação visual do autor

Prints do renderer do jogo, sem HUD. Na visão geral a Percepção está ativa para mostrar o módulo superior completo. Dois módulos horizontais e dois verticais inteiros, paleta harmonizada, vãos transparentes, plataformas alinhadas aos próprios pisos/tampos. Apenas a porta falsa conserva o painel da estante antiga, conforme decisão do autor.

Sete saltos verificados com a física real. Estes prints não são publicação da demo nem aprovação autoral. O HTML de trabalho continua no checkpoint V2 local; a entrega consolidada aguarda revisão.
