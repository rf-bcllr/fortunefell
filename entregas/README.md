## Estado da entrega

Contém arte produzida, fontes, manifestos, documentação e instruções para a outra conta Codex. Não é o jogo atualizado/publicado. As animações candidatas precisam de revisão na integração. Os estados coloridos do boneco, algumas ações de Ínys e a produção dos príncipes permanecem pendentes, descritos na documentação.

Esta branch é uma entrega de arquivos. A branch main permanece separada. Hashes dos ZIPs em SHA256.json. O autor autorizou disponibilizar o material neste repositório público.
