# Pranchas canônicas de Fortune Fell

As pranchas aprovadas pelo autor são a fonte primária para o desenho desses personagens. Consulte a prancha antes de criar ou revisar um sprite, retrato, ilustração ou cutscene. Use Idhrí para calibrar a escala de um humano adulto, as proporções, o contorno, a resolução e a quantidade de detalhe. Adapte a altura e as proporções à idade e ao povo de cada personagem.

O autor enviou as onze pranchas no chat. As imagens ficaram acessíveis para consulta visual. O arquivamento no GitHub ainda depende dos arquivos-fonte. Os nomes-base abaixo são reservados para os originais, com extensão conforme o arquivo recebido. Preserve a resolução, o enquadramento e os bytes do arquivo.
